Formulario de búsqueda y parámetros de Maigret

1. Entrada de texto a buscar

Uno o varios términos separados por espacios, comas o saltos de línea (ej.: user1 user2 user3). También puedes usar prefijos tipo:valor como vk_id:12345.

Introduce al menos un término de búsqueda (username o identificador).
Tipo de término introducido (--id-type / modo --ids)

Nota: en la CLI de Maigret se usa --id-type <tipo> (o tipo:valor vía --input-file) en lugar de un flag genérico --ids. En la web puedes probar todos los IDs numéricos a la vez.

2. Lugar de salida

Ruta donde Maigret guardará los informes. Si indicas una carpeta distinta a reports, la web exportará allí los archivos además de permitir su descarga directa.

3. Formato de salida

    Parámetros principales para búsquedas SOCMINT y exportación en Maigret
    Parámetro CLI Función en la consulta SOCMINT
    --top-sites N Prioriza las N plataformas más relevantes por tráfico global (o usa -a para consultar todo el catálogo).
    --tags coding,social Filtra el rastreo por categoría de plataforma o país (ej. photo,dating, us) y evita ruido irrelevante.
    --json simple / ndjson simple genera un fichero JSON limpio listo para ingesta o análisis con jq; ndjson escribe un objeto por línea.
    --ids → --id-type <tipo> Trata el término introducido como un identificador numérico en lugar de alias (en Maigret CLI se especifica con --id-type, p. ej. vk_id, gaia_id, steam_id, qq_id, o usando el modo automático en esta web).
    --keywords python rust Busca palabras clave dentro del HTML de cada perfil hallado y marca las coincidencias con [++].
    --folderoutput / -fo Define la carpeta de salida donde se almacenan los informes (--html, --pdf, --xmind, --csv, --txt, --graph, --neo4j).
    --ai Genera un resumen de investigación asistido por IA sobre los hallazgos (requiere OPENAI_API_KEY).
